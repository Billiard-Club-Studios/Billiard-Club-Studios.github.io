Hosting

This website is hosted by GitHub Pages (GitHub, Inc., USA). When you open a page, your browser connects to GitHub's servers. GitHub logs and stores your IP address for security purposes and receives the technical data your browser sends, such as the requested page, the date and time, and browser and device information. We run no analytics and keep no visitor logs of our own.

We use hosting to deliver and secure the website. Legal basis: our legitimate interest in a working, secure website (Art. 6(1)(f) GDPR). GitHub decides how long it keeps this data; see the GitHub Privacy Statement.

GitHub processes data in the USA. GitHub states that it complies with the EU-U.S. Data Privacy Framework and uses the EU standard contractual clauses.
